Personal Project

Iron Scalper

A Python algorithmic trading robot for MetaTrader 5 that trades XAUUSD using two strategies, enforced risk rules and a live web dashboard.

  • Python
  • MetaTrader 5
  • SQLite
  • Flask
Problem
Manual trading is inconsistent and hard to risk-manage.
Solution
An automated system that runs two strategies, enforces risk limits and stores every trade.
My Role
Solo developer — architecture, strategies, risk manager and dashboard.
Key Features
Daily Breakout strategy, London Scalper, 1% per-trade risk cap, 3% daily cap, 3-loss circuit breaker, SQLite logging, password-protected dashboard, state persistence, spread check, MT5 auto-reconnect.
What I Learned
Multi-strategy architecture, broker API integration, risk-first design and database-driven web dashboards.
